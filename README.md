# Каталог настольных игр (РГР, Вариант №38)

Консольное приложение на Java для анализа каталога настольных игр.

## Требования и сборка
- **Версия Java:** Java 25 (совместимо с Java 21+)
- **Система сборки:** Maven

### Сборка и запуск из терминала:
```bash
mvn compile
java -cp target/classes rgr.Main
```

## Формат входных данных
Данные считываются из файла `data/games.txt`. Каждая строка имеет формат:
`название;жанр;мин_игроков;макс_игроков;рейтинг`

Пример валидной строки:
```text
Carcassonne;Strategy;2;5;8.0
```
*Примечание: повреждённые строки автоматически пропускаются с записью предупреждения в лог.*
